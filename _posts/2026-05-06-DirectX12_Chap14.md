테셀레이션은 원래 평면도형을 빈틈없이 붙이는 방식을 말한다. 그래픽스에서의 테셀레이션 스테이지는 버택스 셰이더에서 만들어진 삼각형을 더 작은 삼각형으로 쪼개는 과정이다.

테셀레이션 스테이지는 버택스 셰이더와 픽셀셰이더 사이에 있는데 이곳에서 정점을 추가하고 추가적인 계산이 가능하다. 물론 이것 역시 필수적인 단계는 아니다.

**그냥 처음부터 버택스를 많이 만들면 되는 문제 아닌가?**

맞는 말이지만 이렇게 따로 만든 데에는 세 가지 이유가 있다.
- LOD(Level Of Detail)의 적용에 용이함.
- 물리, 애니메이션에 효율성이 높아짐
- 메모리를 아낄 수 있음.

--- (LOD는 멀리 있는 물체의 폴리곤을 줄여서 성능을 높이는 기술이다.) ---

원래 알고있던 VS(버택스 셰이더)와 PS(프래그먼트 셰이더)사이에 처음보는 세단계가 있다. 차근차근 과정을 알아보자.

### 헐 셰이더 (Hull Shader)

헐 셰이더에서는 VS에서 전달받은 도형을 어떻게 나눌 것인지 정의한다. VS에서는 각 정점(버택스)라고 불리는 것을 해당 스테이지에서는 Control Point로 바꿔 부른다. 그 이유는 정점의 위치를 변화시키거나 개수를 늘리기 위한 스테이지이기 때문이라고 짐작해본다.

헐 셰이더는 두 가지 단계로 구분된다.
#### 1. Constant Hull Shader
```cpp
struct	PatchTess
{
  float	EdgeTess[4] : SV_TessFactor;
  float	InsideTess[2] : SV_InsideTessFactor;
};

PatchTess ConstantHS(InputPatch<VertexOut, 4> patch,
uint patchID : SV_PrimitiveID)
{
  PatchTess pt;

  pt.EdgeTess[0] = 3;
  pt.EdgeTess[1] = 3;
  pt.EdgeTess[2] = 3;
  pt.EdgeTess[3] = 3;
  pt.InsideTess[0] = 3;
  pt.InsideTess[1] = 3;
  return pt;
}
```
Patch : 상수 헐 셰이더에 한번에 들어오는 점의 집합

Tessellation factor : 도형을 어떻게 나눌 것인지 정하는 파라미터

상수 헐 셰이더에서는 들어온 patch를 이용해서 Tessellation factor를 정하고 내보내는 역할을 한다. PatchTess에 보면 4개의 인덱스를 가진 Edgetess, 2개의 인덱스를 가진 InsideTess가 있다.

#### 2. Control Point Hull Shader
```cpp
struct	HullOut
{
  float3 PosL : POSITION;
};

[domain(“quad”)]
[partitioning(“integer”)]
[outputtopology(“triangle_cw”)]
[outputcontrolpoints(4)]
[patchconstantfunc(“ConstantHS”)]
[maxtessfactor(64.0f)]
HullOut	HS(InputPatch<VertexOut,4>	p,	
uint i : SV_OutputControlPointID,
uint patchId : SV_PrimitiveID)
{
  HullOut	hout;
  hout.PosL	=	p[i].PosL;
  return	hout;
}

```
해당 셰이더에서는 상수 헐 셰이더에서 전달받은 컨트롤 포인트들의 위치를 제어할 수 있다.

## 테셀레이션
여기서는 실제로 도형이 어떻게 나누어지는지 알아보자. 패치는 quad, triangle 두 종류가 가장 대표적으로 쓰인다. quad는 4개의 edgeTess, 2개의 InsideTess를 사용하고 triangle은 3개, 1개를 사용한다.
