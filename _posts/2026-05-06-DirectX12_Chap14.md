<figure>
  <img src="/assets/images/chap14/DirectX12_Chap14(2).png" alt="테셀레이션 이미지">

테셀레이션은 원래 평면도형을 빈틈없이 붙이는 방식을 말한다. 그래픽스에서의 테셀레이션 스테이지는 버택스 셰이더에서 만들어진 삼각형을 더 작은 삼각형으로 쪼개는 과정이다.

테셀레이션 스테이지는 버택스 셰이더와 픽셀셰이더 사이에 있는데 이곳에서 정점을 추가하고 추가적인 계산이 가능하다. 물론 이것 역시 필수적인 단계는 아니다.

**그냥 처음부터 버택스를 많이 만들면 되는 문제 아닌가?**

맞는 말이지만 이렇게 따로 만든 데에는 세 가지 이유가 있다.
- LOD(Level Of Detail)의 적용에 용이함.
- 물리, 애니메이션에 효율성이 높아짐
- 메모리를 아낄 수 있음.

--- (LOD는 멀리 있는 물체의 폴리곤을 줄여서 성능을 높이는 기술이다.) ---

## 헐 셰이더 (Hull Shader)

헐 셰이더에서는 VS에서 전달받은 도형을 어떻게 나눌 것인지 정의한다. VS에서는 각 정점(버택스)라고 불리는 것을 해당 스테이지에서는 Control Point로 바꿔 부른다. 그 이유는 정점의 위치를 변화시키거나 개수를 늘리기 위한 스테이지이기 때문이라고 짐작해본다.

헐 셰이더는 두 가지 단계로 구분된다.
### 1. Constant Hull Shader
<span class="code-fold-name">PatchTess / ConstantHS</span>
```cpp
struct	PatchTess
{
  float	EdgeTess[4] : SV_TessFactor; // 모서리 divide 파라미터
  float	InsideTess[2] : SV_InsideTessFactor; // 내부 divide 파라미터
};

PatchTess ConstantHS(InputPatch<VertexOut, 4> patch,
uint patchID : SV_PrimitiveID)
{
  PatchTess pt;

  pt.EdgeTess[0] = 3;
  pt.EdgeTess[1] = 3;
  pt.EdgeTess[2] = 3;
  pt.EdgeTess[3] = 3;
  pt.InsideTess[0] = 3;
  pt.InsideTess[1] = 3;
  return pt;
}
```
Patch : 상수 헐 셰이더에 한번에 들어오는 점의 집합

Tessellation factor : 도형을 어떻게 나눌 것인지 정하는 파라미터

상수 헐 셰이더에서는 들어온 patch를 이용해서 Tessellation factor를 정하고 내보내는 역할을 한다. PatchTess에 보면 4개의 인덱스를 가진 Edgetess, 2개의 인덱스를 가진 InsideTess가 있다.

### 2. Control Point Hull Shader
<span class="code-fold-name">HullOut / HS</span>
```cpp
struct	HullOut
{
  float3 PosL : POSITION;
};

[domain(“quad”)] // 패치의 모양 결정
[partitioning(“integer”)] // 
[outputtopology(“triangle_cw”)] // culling face 결정
[outputcontrolpoints(4)]
[patchconstantfunc(“ConstantHS”)]
[maxtessfactor(64.0f)]
HullOut	HS(InputPatch<VertexOut,4>	p,
uint i : SV_OutputControlPointID,
uint patchId : SV_PrimitiveID)
{
  HullOut	hout;
  hout.PosL	=	p[i].PosL;
  return	hout;
}
```
해당 셰이더에서는 상수 헐 셰이더에서 전달받은 컨트롤 포인트들의 위치를 제어할 수 있다.

#### Tessellation factor 결정 시 고려사항
Tessellation factor에 따라 하드웨어가 알아서 나눠주기 때문에 factor를 잘 선택해야한다. 고려사항은 다음과 같다.
- 카메라로부터의 거리
- 화면의 해상도
- 카메라의 시점
- Roughness (일반적으로 거친 표면이 더 많은 테셀레이션 factor를 요구함)


## Domain Shader
<span class="code-fold-name">DomainOut / DS</span>
```cpp
struct DomainOut
{
  float4 PosH : SV_POSITION;
};
[domain(“quad”)] // 패치의 모양 결정
DomainOut DS(PatchTess patchTess,	
float2 uv : SV_DomainLocation,	
const OutputPatch<HullOut,4> quad)
{
  DomainOut dout;
  float3 v1 = lerp(quad[0].PosL, quad[1].PosL, uv.x);	
  float3 v2 = lerp(quad[2].PosL, quad[3].PosL, uv.x);	
  float3 p = lerp(v1, v2, uv.y);	
  float4 posW = mul(float4(p, 1.0f), gWorld);
  dout.PosH = mul(posW, gViewProj);
  return dout;
}
```

도메인 셰이더는 테셀레이션 스테이지에서 생성된 각 vertex마다 한번씩 호출된다. 파라미터로 받은 매개변수 좌표와 제어점을 이용해서 실제 3D정점 위치를 계산해야한다.

결국 전체적인 Tessellation의 과정은 다음과 같다고 볼 수 있다.
1. VS에서 Control Point를 넘겨주면 Constant HS에서 tessellation factor를 만든다.
2. Control Point HS에서 Control Point들을 조정한다.
3. Tessellation Stage에서는 하드웨어가 자동으로 도형을 나누어준다.
4. Domain Shader에서는 정점을 하나씩 돌면서 정점의 위치를 조정한다.

## 3차 베지어 Quad Patch
이번에는 테셀레이션을 이용해서 곡면을 만드는 방법을 알아보자. 이를 위해서 베지어 곡선을 알아야 한다. 

<figure>
  <img src="/assets/images/chap14/DirectX12_Chap14(6).jpg" alt="Quad 테셀레이션 전체 구조">
  <figcaption>Quad 테셀레이션 전체 구조</figcaption>

Blender나 Unity등등을 다루다 보면 그래프를 조절하는 방법중에 베지어 곡선을 본 적이 있을 것이다. 단순히 로그, 지수 형태로 선을 조절하지 않고 내가 원하는대로 곡선을 만들 수 있다는 장점이 있다.

포인트는 **여러개의 점을 기준으로 선을 만들어내고, 복잡한 곡선일 수록 점이 여러개 필요하다.**

일직선으로 위치하지 않은 점 $\mathbf{p}_0$, $\mathbf{p}_1$, $\mathbf{p}_2$가 있다고 하자.

$$
\mathbf{p}_0^1 = (1-t)\mathbf{p}_0 + t\mathbf{p}_1
$$

$$
\mathbf{p}_1^1 = (1-t)\mathbf{p}_1 + t\mathbf{p}_2
$$

$$
\begin{aligned}
\mathbf{p}(t) &= (1-t)\mathbf{p}_0^1 + t\mathbf{p}_1^1 \\
              &= (1-t)\bigl((1-t)\mathbf{p}_0 + t\mathbf{p}_1\bigr) + t\bigl((1-t)\mathbf{p}_1 + t\mathbf{p}_2\bigr) \\
              &= (1-t)^2\mathbf{p}_0 + 2(1-t)t\mathbf{p}_1 + t^2\mathbf{p}_2
\end{aligned}
$$

파라미터 $\mathbf{t}$로 선형보간을 하면 세 점 사이에 위치를 구할 수 있다. 해당 공식을 2차 베지어 곡선이라고 부른다.

<script>
(function() {
  var canvas = document.getElementById('quadBezierCanvas');
  var ctx = canvas.getContext('2d');
  var slider = document.getElementById('quadBezierT');
  var valLabel = document.getElementById('quadBezierVal');

  var pts = [
    { x: 60,  y: 300 },
    { x: 240, y: 40  },
    { x: 420, y: 300 }
  ];
  var dragging = null;

  function lerp(a, b, t) { return { x: a.x + (b.x - a.x) * t, y: a.y + (b.y - a.y) * t }; }

  function draw() {
    var t = slider.value / 100;
    valLabel.textContent = 't = ' + t.toFixed(2);
    ctx.clearRect(0, 0, canvas.width, canvas.height);

    // 조절선 (점선)
    ctx.strokeStyle = '#2a2a3a'; ctx.lineWidth = 1.5; ctx.setLineDash([5,4]);
    ctx.beginPath(); ctx.moveTo(pts[0].x, pts[0].y); ctx.lineTo(pts[1].x, pts[1].y); ctx.lineTo(pts[2].x, pts[2].y); ctx.stroke();
    ctx.setLineDash([]);

    // 곡선
    ctx.strokeStyle = '#7c6aff'; ctx.lineWidth = 2.5;
    ctx.shadowColor = 'rgba(124,106,255,0.4)'; ctx.shadowBlur = 8;
    ctx.beginPath();
    for (var i = 0; i <= 100; i++) {
      var ti = i / 100, mt = 1 - ti;
      var x = mt*mt*pts[0].x + 2*mt*ti*pts[1].x + ti*ti*pts[2].x;
      var y = mt*mt*pts[0].y + 2*mt*ti*pts[1].y + ti*ti*pts[2].y;
      i === 0 ? ctx.moveTo(x, y) : ctx.lineTo(x, y);
    }
    ctx.stroke();
    ctx.shadowBlur = 0;

    // 보간 과정
    var Q0 = lerp(pts[0], pts[1], t);
    var Q1 = lerp(pts[1], pts[2], t);
    var B  = lerp(Q0, Q1, t);

    ctx.strokeStyle = 'rgba(255,106,124,0.6)'; ctx.lineWidth = 1.2; ctx.setLineDash([3,3]);
    ctx.beginPath(); ctx.moveTo(Q0.x, Q0.y); ctx.lineTo(Q1.x, Q1.y); ctx.stroke();
    ctx.setLineDash([]);

    // 시작/끝점
    [{ p: pts[0], c:'#e8e8f0', l:'P₀' }, { p: pts[2], c:'#e8e8f0', l:'P₂' }].forEach(function(o) {
      ctx.fillStyle = '#2a2a3a'; ctx.beginPath(); ctx.arc(o.p.x, o.p.y, 7, 0, Math.PI*2); ctx.fill();
      ctx.strokeStyle = o.c; ctx.lineWidth = 1.5; ctx.beginPath(); ctx.arc(o.p.x, o.p.y, 7, 0, Math.PI*2); ctx.stroke();
      ctx.fillStyle = '#7a7a90'; ctx.font = '12px JetBrains Mono,monospace'; ctx.fillText(o.l, o.p.x+11, o.p.y-9);
    });
    // 제어점
    ctx.fillStyle = 'rgba(124,106,255,0.2)'; ctx.beginPath(); ctx.arc(pts[1].x, pts[1].y, 7, 0, Math.PI*2); ctx.fill();
    ctx.strokeStyle = '#7c6aff'; ctx.lineWidth = 1.5; ctx.beginPath(); ctx.arc(pts[1].x, pts[1].y, 7, 0, Math.PI*2); ctx.stroke();
    ctx.fillStyle = '#7c6aff'; ctx.font = '12px JetBrains Mono,monospace'; ctx.fillText('P₁', pts[1].x+11, pts[1].y-9);

    // Q 점
    [{ p: Q0, l:'Q₀' }, { p: Q1, l:'Q₁' }].forEach(function(o) {
      ctx.fillStyle = 'rgba(255,106,124,0.7)'; ctx.beginPath(); ctx.arc(o.p.x, o.p.y, 4, 0, Math.PI*2); ctx.fill();
      ctx.fillStyle = '#ff6a7c'; ctx.font = '11px JetBrains Mono,monospace'; ctx.fillText(o.l, o.p.x+7, o.p.y-7);
    });

    // B(t)
    ctx.fillStyle = '#7c6aff'; ctx.shadowColor = 'rgba(124,106,255,0.6)'; ctx.shadowBlur = 10;
    ctx.beginPath(); ctx.arc(B.x, B.y, 8, 0, Math.PI*2); ctx.fill();
    ctx.shadowBlur = 0;
    ctx.fillStyle = '#e8e8f0'; ctx.font = 'bold 12px JetBrains Mono,monospace'; ctx.fillText('B(t)', B.x+12, B.y-10);
  }

  function hitTest(e) {
    var r = canvas.getBoundingClientRect();
    var mx = (e.clientX - r.left) * (canvas.width / r.width);
    var my = (e.clientY - r.top)  * (canvas.height / r.height);
    for (var i = 0; i < pts.length; i++) {
      var dx = pts[i].x - mx, dy = pts[i].y - my;
      if (Math.sqrt(dx*dx+dy*dy) < 14) return i;
    }
    return null;
  }

  canvas.addEventListener('mousedown',  function(e){ dragging = hitTest(e); });
  canvas.addEventListener('mousemove',  function(e){ if (dragging === null) return; var r = canvas.getBoundingClientRect(); pts[dragging].x = (e.clientX-r.left)*(canvas.width/r.width); pts[dragging].y = (e.clientY-r.top)*(canvas.height/r.height); draw(); });
  canvas.addEventListener('mouseup',   function(){ dragging = null; });
  canvas.addEventListener('mouseleave',function(){ dragging = null; });
  canvas.addEventListener('touchstart', function(e){ e.preventDefault(); dragging = hitTest(e.touches[0]); }, {passive:false});
  canvas.addEventListener('touchmove',  function(e){ e.preventDefault(); if (dragging===null) return; var r=canvas.getBoundingClientRect(); pts[dragging].x=(e.touches[0].clientX-r.left)*(canvas.width/r.width); pts[dragging].y=(e.touches[0].clientY-r.top)*(canvas.height/r.height); draw(); }, {passive:false});
  canvas.addEventListener('touchend',  function(){ dragging=null; });

  slider.addEventListener('input', draw);
  draw();
})();
</script>

### 8번. Bezier Patch를 수정해서 라이팅의 효과를 받는 곡면을 그려라. (삼각형의 세 점을 이용하면 normal 벡터를 구할 수 있다.)

이번엔 라인이 아니라 라이팅이 구현된 곡면을 렌더링하는 문제이다. 문제에서 세 점의 외적을 통해 normal을 구하라고 했는데 나는 더 쉬운 방법으로 구현했다.

<span class="code-fold-name">BernsteinBasis / DS / PS</span>
```cpp
float4 BernsteinBasis(float t)
{
    float invT = 1.0f - t;

    return float4( invT * invT * invT,
                   3.0f * t * invT * invT,
                   3.0f * t * t * invT,
                   t * t * t );
}

float4 dBernsteinBasis(float t) // 미분
{
    float invT = 1.0f - t;

    return float4( -3 * invT * invT,
                   3 * invT * invT - 6 * t * invT,
                   6 * t * invT - 3 * t * t,
                   3 * t * t );
}

float3 CubicBezierSum(const OutputPatch<HullOut, 16> bezpatch, float4 basisU, float4 basisV)
{
    float3 sum = float3(0.0f, 0.0f, 0.0f);
    sum  = basisV.x * (basisU.x*bezpatch[0].PosL  + basisU.y*bezpatch[1].PosL  + basisU.z*bezpatch[2].PosL  + basisU.w*bezpatch[3].PosL );
    sum += basisV.y * (basisU.x*bezpatch[4].PosL  + basisU.y*bezpatch[5].PosL  + basisU.z*bezpatch[6].PosL  + basisU.w*bezpatch[7].PosL );
    sum += basisV.z * (basisU.x*bezpatch[8].PosL  + basisU.y*bezpatch[9].PosL  + basisU.z*bezpatch[10].PosL + basisU.w*bezpatch[11].PosL);
    sum += basisV.w * (basisU.x*bezpatch[12].PosL + basisU.y*bezpatch[13].PosL + basisU.z*bezpatch[14].PosL + basisU.w*bezpatch[15].PosL);

    return sum;
}

[domain("quad")]
DomainOut DS(PatchTess patchTess,
             float2 uv : SV_DomainLocation,
             const OutputPatch<HullOut, 16> bezPatch)
{
	DomainOut dout;

	float4 basisU  = BernsteinBasis(uv.x);
	float4 basisV  = BernsteinBasis(uv.y);
	float4 dbasisU = dBernsteinBasis(uv.x);
	float4 dbasisV = dBernsteinBasis(uv.y);

	float3 p    = CubicBezierSum(bezPatch, basisU,  basisV);
	float3 dpdu = CubicBezierSum(bezPatch, dbasisU, basisV);  // u 방향 접선
	float3 dpdv = CubicBezierSum(bezPatch, basisU,  dbasisV); // v 방향 접선

	float3 normal = normalize(cross(dpdu, dpdv));

	float4 posW  = mul(float4(p, 1.0f), gWorld);
	dout.PosH    = mul(posW, gViewProj);
	dout.PosW    = posW.xyz;
	dout.NormalW = mul(normal, (float3x3)gWorld);

	return dout;
}

float4 PS(DomainOut pin) : SV_Target
{
	pin.NormalW = normalize(pin.NormalW);

	float3 toEye = normalize(gEyePosW - pin.PosW);

	float4 ambient = gAmbientLight * gDiffuseAlbedo;

	const float shininess = 1.0f - gRoughness;
	Material mat = { gDiffuseAlbedo, gFresnelR0, shininess };
	float3 shadowFactor = 1.0f;
	float4 directLight = ComputeLighting(gLights, mat, pin.PosW,
		pin.NormalW, toEye, shadowFactor);

	float4 litColor = ambient + directLight;
	litColor.a = gDiffuseAlbedo.a;

	return litColor;
}
```
dBernsteinBasis는 베지어 곡선을 미분한 값을 구하는 함수인데, 곡선을 미분하면 해당 곡선의 접선이 나온다. 평면에서 u, v에 대해 미분하여 나온 접선 두 개를 외적하면 normal 벡터를 구할 수 있다.
